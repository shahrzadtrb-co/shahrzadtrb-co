## Selected work

**Automated Measurement Pipeline for Controlled Experiments** — M.Sc. thesis, in progress
Python pipeline that runs controlled experiments at scale, collects performance and energy measurements, and analyses the results in Pandas. Experiment configuration and logging are structured so repeated runs stay comparable across batches. *(Repository private while the thesis is in progress.)*
`Python` `Pandas` `Linux`

**[Privacy–Utility Trade-offs in LLM Code Completion](https://github.com/shahrzadtrb-co/Privacy-Preserving-Techniques-for-LLM-Code-Completion)**
Evaluation pipeline that applies increasing levels of obfuscation to HumanEval prompts, generates completions with CodeT5, and measures the resulting trade-off — privacy via Levenshtein distance, utility via character-level LCS F1 — to find where code quality starts to break down.
`Python` `CodeT5` `HumanEval` `Jupyter`

**[Fuzzy Unlearning on an EEG Classification Model](https://github.com/shahrzadtrb-co/eeg-fuzzy-unlearning)**
Fuzzy machine unlearning in Python to remove individual subjects' contributions from a model trained on multi-subject EEG data, with classification metrics tracked before and after each run to quantify the privacy–utility trade-off.
`Python` `Jupyter`

**[Interactive Data Visualisation Dashboard](https://github.com/shahrzadtrb-co/dataVis_2024)**
Dashboard rendering a 25-column dataset across four linked D3.js charts — sunburst, histogram, box plot, and radar — where selecting a segment in one chart filters the others.
`JavaScript` `D3.js`

**[Trivia Data Visualiser](https://github.com/shahrzadtrb-co/Mini-Visualizer-opentrivia)**
React and TypeScript app that fetches the Open Trivia DB API and visualises questions by category and difficulty, with filtering handled through a custom data-fetching hook.
`React` `TypeScript` `Recharts` `Vite`
