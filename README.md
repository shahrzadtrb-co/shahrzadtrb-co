M.Sc. Computer Science student at the University of Passau. I build backend services and data pipelines in Python and SQL, and I care about trustworthy measurements.

**Now:** My master's thesis measures the energy cost of individual user actions in a real web application. A Docker-based setup on a Raspberry Pi 5 runs a self-hosted ONLYOFFICE instance, Playwright drives it action by action, and CodeCarbon records the energy of each step into structured CSV. Every run also produces an event log for process-mining analysis. The experiments are built to be repeatable: baseline subtraction, randomized run order, thermal checks and a pytest suite.
